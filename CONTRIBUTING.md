# Contributing and Feedback

Thank you for your interest in Old Net X Migrator.

This project uses a **proprietary, closed-source development model**. The public GitHub repository is used for release notes, downloads, documentation, bug reports, and discussion. Source-code contributions and pull requests are **not** generally solicited or accepted without a separate arrangement with the maintainer.

## Helpful contributions

- Report reproducible bugs in [GitHub Issues](https://github.com/Lukass2025/OldNetXMigrator/issues).
- Describe compatibility results for Netscape Navigator 9.0.0.6 on Windows 11 x64.
- Suggest improvements to usability, accessibility, documentation, or testing procedures.
- Share screenshots or logs **after removing private information**.

For bug reports, please include:

1. Old Net X Migrator version.
2. Netscape Navigator version.
3. Windows version and architecture.
4. Steps to reproduce.
5. Expected result and actual result.
6. Relevant screenshots or sanitized error messages, if available.

## Security reports

Please follow [SECURITY.md](SECURITY.md). Do not post credentials, signing material, or security-sensitive proof-of-concept material in public issues.

## Source code and rights

Public issue discussions, suggestions, and bug reports do not constitute an open-source license. Do not upload decompiled or redistributed proprietary code. If a proposed contribution requires code or artwork, discuss its ownership, permission, and any necessary written agreement with the maintainer **before** submitting it.

The project is independent and not affiliated with Netscape, Mozilla, or Microsoft.
